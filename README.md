# 🏜️ 3D Egyptian Pyramid and Desert Environment Simulation

A 3D Egyptian Pyramid and Desert Environment Simulation developed using **Python and OpenGL (PyOpenGL)** as a Computer Graphics Sessional project.

The project creates a 3D Egyptian desert environment featuring pyramids, the Sphinx, a camel, palm trees, clouds, desert dunes, and a glowing sun. Users can explore the scene using keyboard and mouse interactions.

## ✨ Features

- **3D Desert Environment:** Egyptian pyramids, desert dunes, and sky.
- **3D Objects:** Pyramids, Sphinx, camel, palm trees, clouds, and sun.
- **Camera Movement:** Orbit, zoom, and adjust camera angles.
- **Overhead View:** Switch between normal and top camera views.
- **Animation:** Automatic scene animation.
- **Keyboard Interaction:** Control the camera and animation.
- **Mouse Interaction:** Select and drag the sun and camel.
- **Lighting:** OpenGL lighting effects.
- **Fog Effect:** Creates a desert atmosphere.
- **Blending:** Transparency and blending effects.
- **Shadow Effects:** Transparent oval ground-shadow approximations.

## 🛠️ Technologies Used

- **Python 3** – Main programming language.
- **PyOpenGL** – Python bindings for OpenGL.
- **GLUT / FreeGLUT** – Window management, input handling, and animation.
- **GLU** – Camera viewing and perspective projection.

## 📦 Requirements

- Python 3.x
- PyOpenGL
- PyOpenGL_accelerate (optional)
- GLUT / FreeGLUT

## 🚀 Installation and Execution

### 1. Clone the Repository

```bash
git clone https://github.com/Araf105/3D-Egyptian-Pyramid-Desert-Simulation.git
```

### 2. Navigate to the Project Directory

```bash
cd 3D-Egyptian-Pyramid-Desert-Simulation
```

### 3. Install Required Python Packages

```bash
python3 -m pip install PyOpenGL PyOpenGL_accelerate
```

### 4. Run the Project

```bash
python3 main.py
```

## 🎮 Controls

| Key / Input | Action |
|---|---|
| A / D | Orbit around the scene |
| W / S | Zoom in / Zoom out |
| Q / E | Tilt camera up / down |
| Up / Down Arrow | Adjust camera tilt |
| T | Overhead / top view |
| G | Return to normal angled view |
| Space | Pause / Resume animation |
| R | Reset scene |
| Left Mouse Click | Select an object |
| Left Mouse Drag | Move selected object |

## 🎨 Computer Graphics Concepts

This project demonstrates the practical application of fundamental computer graphics concepts:

1. **Basic Shapes:** Construction of objects using geometric primitives.
2. **Circle:** Circular shapes used in scene construction.
3. **Straight Line:** Lines used to construct different objects.
4. **Transformation:** Translation, rotation, and scaling.
5. **3D Objects:** Construction of pyramids and other 3D objects.
6. **Animation:** Timer-based animation.
7. **Keyboard and Mouse Input:** Interactive user controls.
8. **3D Camera Viewing:** Perspective projection and `gluLookAt()`.
9. **Blending:** Transparency and blending effects.
10. **Fog:** Atmospheric fog effect.
11. **Lighting and Shadows:** Lighting and ground-shadow effects.
