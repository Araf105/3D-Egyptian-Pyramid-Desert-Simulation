3D Egyptian Pyramid and Desert Environment Simulation

Install:
    python3 -m pip install PyOpenGL PyOpenGL_accelerate

Run:
    python3 main.py

Camera controls:
    A / D       Orbit around the scene
    W / S       Zoom in / out
    Q / E       Tilt camera up / down
    Up / Down   Tilt camera up / down
    T           Overhead / top view
    G           Return to normal angled view
    Space       Pause / resume animation
    R           Reset scene

The camera smoothly tilts to a near top-down view.
The sun is a filled deep-yellow 3D sphere.
Ground shadows are transparent oval approximations.
